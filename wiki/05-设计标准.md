# 设计标准

## 核心实现约束

1. 确定性状态转换写在 Python，不写在模型提示词。
2. 网页、Feed、API、图片、正文和模型输出都按不可信数据处理。
3. 本地 JSON/Markdown 是事实源；HTML/PDF/Notion 是可重建投影。
4. 访问失败、空结果、部分成功、限流和待验证使用不同状态。
5. 带 Revision 的 Artifact 不覆盖写入。
6. 可变 JSON/Markdown/HTML 使用原子写。
7. 并发共享资源使用显式锁和全局/同域边界。
8. Artifact 路径使用前解析，并验证位于活动数据根。
9. 错误包含对象、阶段、原因和下一修复动作。
10. 公开函数使用类型标注；稳定状态使用显式枚举。

## 模型与 Python 的边界

Hermes 负责：

- 原题的自然目标语言翻译；
- 证据范围内的 TL;DR；
- Brief 重要性和生命周期语义；
- 精选事件选择；
- 三视角研判、反证、情景、行动和跨视角综合。

Python 负责：

- ID、Revision、Hash 和时间窗口；
- 来源、URL、访问状态和时间身份；
- 候选上限、覆盖目标、批次分配和状态转换；
- Schema、跨字段、证据身份和 lineage 校验；
- 原子写、锁、幂等、进度登记和恢复；
- HTML、桌面 HTML、PDF 和 Notion 的确定性投影。

Python 不通过字符串模板补写语义。Hermes 不声明权威访问状态、文件是否存在或发布是否成功。

## 上下文最小化

- `SKILL.md` 保持简洁、过程化；详细规则放在 `references/` 和 Wiki。
- Monitor Snapshot 不直接作为完整模型上下文。
- Context 每来源有界，已富化条目优先保留。
- Brief 子任务只读取自己的 Packet 和列出的正文。
- 主分析只读取最多 18 个候选的 Analysis Packet。
- 指标 Artifact 不保存正文、隐藏推理或工具轨迹。

## 配置规则

- 可部署行为进入 dataclass、枚举或 YAML。
- 来源差异优先用 `SourceConfig`，确实无法表达时才增加 Adapter。
- 发现来源与核心来源必须明确 `bundle`，发现来源报告配额为 0。
- 动态来源页只允许主入口或 `include_domains` 内的 HTTP(S) URL。
- 默认值集中在 `config.py`；兼容旧配置的缺省注入也在加载层完成。
- 环境变量和 CLI 冲突遵循已测试优先级，路径冲突不静默选择。

## 状态设计

- 状态表示事实，不表示 UI 文案。
- `no_items` 只表示成功访问后的空结果。
- Run 本地完成、Tail 完成和 Evaluation 完成是三个独立维度。
- `completed_partial` 表示本地报告可用但存在来源或预算缺口。
- 可重试错误保存结构化状态和下一动作，不依赖日志恢复。

## Artifact 设计

- 不可变 Artifact 名称包含日期、edition 和 Revision。
- 可变指针不复制权威内容，只定位当前版本。
- Context、Session 和批次 Receipt 绑定路径、attempt 或 Hash。
- Report 和 Evaluation 通过 ID + Hash 绑定。
- 桌面 HTML 是投影，不能被后续流程读取为事实源。
- 运行时 `DATA_DIR` 与 Skill 安装目录严格分离。

## 兼容规则

- 旧字段通过集中归一化读取，不在调用方散布兼容分支。
- 新 context 不允许旧草稿绕过当前必填协议。
- 不修改历史不可变 Artifact。
- 兼容转换需要明确警告、迁移说明或 Changelog。
- 删除旧格式支持前先提供迁移工具、Fixture 和测试。

## 测试要求

以下变更必须增加或更新测试：

- 来源 Feed、URL、标题或日期过滤；
- 来源、正文、Run、Authoring 或 Tail 状态；
- 聚类身份、阶段或重要性；
- Context、Brief Plan、批次校验或降级覆盖；
- Schema、编译、跨字段或证据校验；
- 图片安全、缓存、并发或发布；
- Artifact 路径、Revision、原子写或锁；
- HTML、桌面 HTML、PDF、Notion 或 Evaluation；
- 旧 source-index 和旧报告兼容。

## 文档规则

- README 面向用户，描述价值、安装、常用命令、输出和真实示例。
- Wiki 面向维护者，记录当前代码契约和跨模块影响。
- `references/` 保存运行、平台、编辑和第三方配置细节。
- `SKILL.md` 只保留 Agent 执行时必需的过程。
- 版本变化写入 `CHANGELOG.md` 和 Release Notes。
- 示例不得包含真实 Token、本机绝对路径、浏览器数据或未经标记的合成新闻。

## 代码评审清单

- [ ] 新输入被视为不可信数据；
- [ ] 状态没有退化为布尔值或空数组；
- [ ] Artifact 归属数据根且写入原子；
- [ ] 不覆盖不可变 Revision；
- [ ] 兼容旧索引/报告；
- [ ] 前台交付与 Tail 失败相互独立；
- [ ] 新发布行为有失败和重试测试；
- [ ] 文档和命令与实现一致。
