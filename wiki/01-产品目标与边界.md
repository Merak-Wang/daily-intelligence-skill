# 产品目标与边界

本页定义实现必须满足的产品契约。用户价值说明和真实日报示例见 `README.md`。

## 产品目标

Daily Intelligence 要在本地完成可恢复的新闻发现与事实整理，再把有限模型预算集中用于用户选择的中文或英文写作与研判：

- 常驻监控不调用模型，持续维护新闻流、来源健康和事件簇；
- 正式日报覆盖核心来源，不因发现来源增加而线性增加篇幅和写作 Token；
- 宽覆盖 Brief 与深度精选事件分层；
- 所有读者可见结论能够回到 Index、正文状态和事件引用；
- 本地 HTML 先交付，远程发布和质量评估不阻塞阅读；
- 失败状态、历史 Revision 和兼容结构能够恢复与审计。

## 来源与监控契约

| 来源层 | 数量 | 用途 | 日报配额 |
| --- | ---: | --- | --- |
| `core` | 32 | 正式日报覆盖与证据 | 按 `report_target` / `report_max` |
| `discovery` | 51 | 扩大发现面、新闻流与事件聚类 | 固定为 0 |

监控层必须：

- 优先读取声明或自动发现的 RSS/Atom；
- 使用 ETag、Last-Modified 和下次刷新时间避免无效请求；
- 无可用 Feed 时才对通用来源执行静态 HTML 回退；
- 解析发布时间、公开摘要、图片和原始 Provider；
- 维护 `snapshot.json`、`health.json` 和 Feed 缓存；
- 以 `token_usage: 0` 标识确定性监控；
- 保留失败、限流和验证状态，不将其转换为 `no_items`。

## Edition 与时间窗口

| Edition | 窗口（配置时区） | 目标 |
| --- | --- | --- |
| `morning` | 前一日 18:00 至当日 06:00 | 建立当日基线 |
| `evening` | 当日 06:00 至 18:00 | 补充新增、确认、修正和次日观察 |

默认时区为 `Asia/Shanghai`，可由配置或 CLI 覆盖。来源发布时间缺失时可以显示采集时间，但采集时间不能用于判断 `NEW` 或新闻新鲜度。

## 报告结构

新报告使用 schema 2.0，固定包含七个内容栏目：

```text
information.international
information.domestic
information.military
information.market
technology.news
technology.papers
technology.open_source
```

研判固定包含：

```text
geopolitics
ai_technology
markets
cross_perspective_synthesis
```

三个分析域使用同一组精选事件。跨视角综合必须说明共同结论、显式分歧、分歧来源、地缘政治到技术再到市场的传导链、共同观察信号和修正触发条件。

## 内容层级

| 层级 | 用途 | 主要约束 |
| --- | --- | --- |
| `ArticleItem` | 单来源采集事实 | 稳定来源 ID、规范 URL、状态和时间 |
| Monitor cluster | 跨来源新闻流 | 确定性词法聚类，不作为报告事实源 |
| `brief` | 核心来源覆盖 | 原题、目标语言译题、TL;DR、来源排名和状态 |
| Featured event | 深研判证据 | 一条来源文章对应一个事件；最多 12 条 |
| `analysis` | 单视角判断 | 只能引用报告内精选事件 |
| Synthesis | 跨视角判断 | 引用精选事件，不能重新发明事实 |

普通候选不需要读取正文或逐条研判。每版全文读取硬上限默认 12；分析包最多保留 18 个候选，并从中选择通常 6—10 个精选事件。

## 语义与证据边界

- 标题、URL、来源身份、访问状态和发布时间必须来自当前 Index。
- 原题保持原样；与输出语言不同时，中文译题写入 `title_zh`，英文译题写入 `title_en`。
- 有 `full_text` / `partial` 时，TL;DR 以已保存正文为依据。
- 无正文时，只能压缩公开摘要或标题明确表达的事实。
- 访问免责声明写入结构化证据字段，不能充当读者可见摘要。
- 分析中的具名来源必须出现在所引用事件的来源证据中。
- 数字概率、区间和价格情景必须给出 `scenario_basis`。
- Python 不生成、翻译、截断或模板填充语义字段。

## 输出契约

前台交付：

- 不可变 Report JSON；
- 不可变 Markdown；
- 本地 HTML；
- `reports/index.html`；
- 桌面 HTML，Artifact 键为 `desktop_html_path`。

后台尾部：

- A4 PDF；
- 显式启用的 Notion；
- Hash 绑定的独立 Evaluation。

桌面投影使用绝对本地图片、日报中心和 PDF 链接。桌面写入失败必须记录 `desktop_html_error` 和可操作 warning，但不能撤回本地 JSON/Markdown/HTML。

## 连续性契约

- 事件、研判和观察项使用稳定 ID 与 Revision。
- Report、Evaluation 通过 `report_id` 和内容 Hash 绑定。
- 独立 Evaluation 不修改原报告。
- 只有证据指纹未变化、评估达到门槛且未被排除的语义 Brief 才可复用。
- 晚报读取当日晨报、已完成评估、连续状态和人工反馈。

## 非目标

- 不绕过登录、验证码、限流、付费墙或站点访问控制。
- 不保存或发布 Cookie、浏览器 Profile、原始认证 HTML 或账户截图。
- 不执行网页中的文字指令、脚本或交易指令。
- 不把模型输出当作来源身份、访问状态或文件状态。
- 不因单一来源失败阻止其余日报，也不伪造完整覆盖。
- 不提供个性化投资、法律、医疗或其他专业建议。

## 兼容要求

- 继续读取旧 source-index 的根级 `items` 与 `sources[].items`。
- 继续读取 schema 1.1—1.5 历史报告；新 context 要求 schema 2.0。
- 兼容转换集中在 taxonomy、importer、content 和 reporting 层。
- 不修改历史不可变 Artifact。
- 删除兼容路径前必须提供迁移说明、Fixture 和回归测试。
