# 依赖与配置

## Python 依赖

运行依赖定义在 `pyproject.toml`：

| 依赖 | 用途 |
| --- | --- |
| `httpx` | Feed、静态 HTML、正文、图片和 Notion HTTP |
| `beautifulsoup4` | 惰性 HTML 解析与正文清理 |
| `playwright` | Edge/Chromium 采集、验证和 PDF |
| `Pillow` | Raster 图片格式、尺寸和像素校验 |
| `PyYAML` | 来源与 Notion 配置 |
| `jsonschema` | Report Schema 校验 |
| `python-dotenv` | Hermes Home `.env` |
| `reportlab` | PDF 降级输出 |
| `tzdata` | Windows/精简环境 IANA 时区 |

开发依赖：pytest、Ruff、pypdf。

## 外部依赖

- Hermes Agent / Gateway：运行 Skill 与独立 Evaluation；
- Microsoft Edge：Windows 浏览器回退和默认 PDF；
- Playwright Chromium：非 Windows 浏览器；
- Notion API：仅显式 `--publish`；
- 公共 DNS：仅用于图片公共地址确认；
- 操作系统 Desktop：HTML 投影目标，可配置覆盖。

Python 包本身不直接调用模型供应商 API。

## Skill 资源目录

`project_root()` 依次检查：

1. `DAILY_INTEL_SKILL_DIR`；
2. 当前 Python 包的源码/安装根；
3. Hermes 标准 Skill 目录；
4. 当前工作目录；
5. Hermes `skills/*/daily-intelligence`。

候选目录必须同时包含：

```text
SKILL.md
configs/sources.yaml
schemas/report.schema.json
```

打包和安装测试必须覆盖非源码工作目录。

## 环境变量

| 变量 | 用途 |
| --- | --- |
| `HERMES_HOME` | 覆盖 Hermes Home |
| `DAILY_INTEL_SKILL_DIR` | 覆盖 Skill 资源根 |
| `DAILY_INTEL_DATA_DIR` | 运行数据根 |
| `DAILY_INTEL_PROFILE_DIR` | 专用浏览器 Profile |
| `DAILY_INTEL_BROWSER_CHANNEL` | Playwright Channel |
| `NOTION_TOKEN` | 可选 Notion Token |
| `NOTION_DATA_SOURCE_ID` | 可选 Notion Data Source |

CLI 启动时读取 `<HERMES_HOME>/.env`，不覆盖已有进程变量。桌面路径不使用环境秘密；通过 `output.desktop_dir` 配置。

## 参数优先级

### 来源配置与时区

1. `--config` 指定 YAML；
2. 否则 Skill 内 `configs/sources.yaml`。

`--timezone` 覆盖 YAML 的 `timezone`。

### 数据根

1. `--data-dir`；
2. `DAILY_INTEL_DATA_DIR`；
3. `<HERMES_HOME>/daily-intelligence`。

参数与环境变量解析到不同目录时命令失败。只有 `data-root adopt` 允许显式迁移。

### 浏览器 Profile

1. 子命令 `--profile-dir`；
2. `browser.profile_dir_env` 指向的变量；
3. `<HERMES_HOME>/browser-profiles/daily-intelligence`。

### Browser Channel

1. 子命令 `--browser-channel`；
2. `browser.channel_env`；
3. `browser.default_channel`；
4. Windows `msedge`，其他平台 Playwright 默认浏览器。

## SourceConfig

| 类别 | 字段 |
| --- | --- |
| 身份 | `id`、`name`、`enabled` |
| 来源层 | `role`、`tier`、`bundle` |
| 分类 | `module`、`category`、`language`、`region` |
| 入口 | `url`、`feed_urls`、`explore_urls`、`mode`、`adapter` |
| Monitor | `monitor_enabled`、`refresh_interval_minutes`、`feed_item_limit` |
| 过滤 | `include_domains`、`article_patterns`、`exclude_patterns`、`exclude_title_patterns` |
| 正文 | `content_selectors`、`wait_ms` |
| 数量 | `max_items`、`report_target`、`report_max` |

加载时校验：

- ID 唯一；
- taxonomy 有效；
- `report_target <= report_max <= budget.report_items_per_source`；
- 发现来源由加载器强制日报配额为 0；
- 未知 Adapter 在采集时给出可用名称。

## MonitorConfig

默认字段：

```yaml
monitor:
  enabled: true
  sources_file: discovery-sources.yaml
  refresh_before_edition: true
  reuse_fresh_snapshot_before_edition: true
  auto_discover_feeds: true
  html_fallback: true
  request_timeout_seconds: 10
  global_concurrency: 16
  per_domain_concurrency: 2
  max_feed_bytes: 2097152
  max_items_per_feed: 40
  max_age_hours: 168
  snapshot_max_age_minutes: 90
  default_refresh_interval_minutes: 30
  cluster_similarity_threshold: 0.68
```

MonitorConfig 只影响零 Token 新闻流和正式采集前的 Snapshot 复用，不修改核心日报配额。

## BrowserConfig 与 BudgetConfig

BrowserConfig 区分：

- 正式索引预取并发；
- 正文浏览器并发；
- HTTP、导航和等待超时。

BudgetConfig 控制：

```yaml
budget:
  max_runtime_seconds: 600
  max_agent_tokens: 10000000
  context_items_per_source: 25
  report_items_per_source: 15
  max_fulltext_per_run: 12
```

总运行时限包含 120 秒分析预留。预算必须通过 AppConfig 注入，不在模块中复制一套默认值。

## MediaConfig

```yaml
media:
  enabled: true
  max_images_per_report: 1000
  max_image_bytes: 8388608
  max_total_bytes: 83886080
  max_image_pixels: 25000000
  request_timeout_seconds: 10
  max_redirects: 5
  global_concurrency: 12
  per_domain_concurrency: 2
  cache_success_ttl_hours: 168
  cache_failure_retry_minutes: 60
```

每图大小还必须满足 Notion 直接上传约束。图片数量是成功上限，不代表遇到失败候选后立即停止补位。

## OutputConfig

```yaml
output:
  language: zh-CN
  formats:
    - html
    - pdf
  pdf_engine: edge
  open_after_finalize: false
  copy_html_to_desktop: true
  desktop_dir:
```

规则：

- `language` 只允许 `zh-CN` 或 `en`，默认 `zh-CN`；
- `run-edition --language` 和 `build-context --language` 可覆盖本次运行，run 会固定该值供后续阶段使用；
- 支持 `html`、`pdf`；
- PDF 要求 HTML；
- `pdf_engine` 为 `edge`、`reportlab` 或 `auto`；
- `open_after_finalize` 默认关闭，避免计划任务弹窗；
- 旧配置未声明 `copy_html_to_desktop` 时，加载器注入 `true`；
- `desktop_dir` 必须是绝对路径；空值使用当前用户 Desktop；
- Notion 不属于 `formats`，由 `--publish` 控制。

低层单元测试可直接构造 `OutputConfig(copy_html_to_desktop=False)`，避免写用户桌面。

## 动态来源页

`DATA_DIR/state/source-pages.json` 与仓库 YAML 分离。写入校验：

- 绝对 HTTP(S)；
- 主机属于入口域或 `include_domains`；
- 每来源最多五页；
- `approved` 状态；
- 不允许文章页、搜索噪音或跨域页面。

## Notion 配置

`configs/notion.yaml` 定义 API 版本、属性映射和兼容 Profile。发布器先读取目标 Data Source Schema，再选择完全匹配的 Profile。缺失字段或类型错误返回可操作列表，不自动修改远程数据库。

用户凭证和数据库准备见 `references/notion-setup.md`。
